# USTAAD — AI Learning Platform
### Seekho. Karo. Kamao.

Professional skills learning platform powered by AI.
Built for Pakistan. ustaad.earn4pk.com

## Stack
- **Backend**: Python FastAPI
- **Database**: Supabase (PostgreSQL)
- **AI**: Claude API (Anthropic)
- **Frontend**: React + Vite

## Setup

### Backend
```bash
cd backend
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
cp .env.example .env
# Fill in .env with your keys
uvicorn main:app --reload
```

### API Docs
Visit http://localhost:8000/docs
